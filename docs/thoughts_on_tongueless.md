# タングレス所感

樹脂やアルミなど、
やわらかいワークのめねじを補強する「ヘリカルインサート」。
備忘も兼ねて、以前に比較・検討していたのですが。
結局のところ、実際に触ってみないと判断できんということで。
第一選択に挙げていたタングレス型のインサートコイルを、
とりあえず導入してみました。
その所感です。

### 関連記事

- [ヘリサートと、Eサートと、エンザートと](helical_insert.md)



## 良いところ

結論からいえば、
いまのところタングレスは好感触です。
ひとたび揃えてしまえば、けっこうつかえそう。
ということで、ひとまずのファースト・インプレッションとして、
よさげだった点から挙げてみます。

### 挿入作業

事前に想像していたとおりで、
タングレスの挿入作業はたしかに簡単でした。
挿入工具をまっすぐ下穴にあてて、
右回しに、とまるまでねじ込むだけです。
挿入深さはあらかじめ挿入工具側で設定しておきます。

挿し終わったら、特別な操作はなにもせず、
そのまま左回しに戻すだけでOKです。
挿入工具はコイルの切り欠きを右回し方向に押しているだけなので、
逆回しにすれば自動的に外れます。
下穴のなかにコイルを置いてくるだけ、っていう感じ。

ヘリカルインサート一般の性質として、
コイルは本来の径より少しすぼまって挿入されます。
これがもとに戻ろうとする力で下穴の内壁に押しつくため（スプリングバック）、
単に置いてくるだけでも、抜けてこないワケです。
これはタングレスだけでなく、
普通のヘリサートでもおなじですね。

### 挿入前の準備

挿入前の準備作業も、思った以上に簡単です。
まず挿入工具先端へのコイルのセットは、
爪にひっかかって止まるまでねじ込むだけ。
工具の爪がコイルの切り欠きにかかった段階で、
それ以上ねじ込めなくなるので、
どこまでいれるか悩む必要はありません。

また、コイル装着後は挿入深さの設定がありますが、
これも単純です。
挿入工具の柄の部分が高ナット状の筒になっているので、
これをまわして、
コイルにあたるひと山手前まで寄せておきます。
この状態で、ダブルナットで固定すればOK。
いちおうスパナをかける面が切られていますが、
手回しで充分です。

このセッティングにより、挿入後のコイルの手前づらが、
ワーク表面から1回転引っ込んだ位置になります。
挿入後のコイルがワークから出っ張っているのはもちろん、
深く入りすぎていてもつかいにくいですからね。
つかうコイルがおなじなら、
この深さ設定は最初に一度すればよく、
毎回は必要ありません。

なお、タングレスのセールスポイントに
「コイルに裏表がないので、挿入工具へのセットの向きを気にしなくてよい」
という点があります。
……が、正直これは感じていません。
わたしの場合、一度に行なう施工がせいぜい10箇所くらいだからです。
何十箇所も連続して施工する場合は、
それもメリットになるのかもしれません。

### タップたて

下穴にタップを切るのも、
予想どおりさほど面倒さはないです。
径が特殊なだけで、普通のタッピングです。
インサートをつかいたいということは、
母材が柔らかい素材なのは確定していますしね。

### ランニングコスト

コイル1個あたりの価格も魅力です。
購入したアキュレイトのものだと、
50個入りで2千円くらい。
なので、1個40円前後の計算です。
練習などで消費するのも、これくらいなら気になりません。



## 微妙 or 不明なところ

褒めちぎっても信用ならないと思うので、
微妙っぽく感じる点も続けて書いておきます。

### 挿入工具の初期コスト

ともかくこれが最大のネックです。
挿入工具が1個あたり1.3万円。
ねじ径間で互換はないので、
必要なサイズぶんそれぞれ購入が要ります。
とりあえず当教室では、
M2・3・4・5・6を揃えました。

挿入工具はミリねじ用・インチねじ用がそれぞれあり、
当然互換はありません。
また挿入工具はサイズ違い以外に、
フリータイプ用・ロッキングタイプ用という型違いがあります。
これはコイル側の種類の違いです。
フリータイプは、普通のヘリカルインサート。
対してロッキングタイプは、
コイルの中間部に抜け防止の機構がついた特殊なコイルです。
これらの挿入工具にも互換がないので、
ロッキングタイプもつかいたければ、
各サイズの挿入工具をさらにべつで買う必要があります。

### 下穴用タップ・ドリルの初期コスト

下穴としてあけるタップも専用サイズで、
一般的なタップは流用できません。
なので全サイズ、それぞれ買う必要があります。
径によりますが、1本2千円強から4千円ぐらい。
地味に出費がかさみます。

さらにうっかりしていましたが、
このタップ用の下穴ドリルも微妙なサイズになるので、
もっていなければ追加で買わないといけません。
わたしの場合、0.1mm刻みの&#x2300;1&ndash;6mmのドリルセットがあるので、
M5の下穴（&#x2300;5.2mm）までは手持ちでなんとかなりました。
ただ、M6用の&#x2300;6.3mmはもっていないので、
買うよりしょうがありません。

| コイル | インサート用タップ下穴 |
| ------ | ---------------------- |
| M2     | 2.1 mm                 |
| M2.5   | 2.6 mm                 |
| M2.6   | 2.8 mm                 |
| M3     | 3.1 mm                 |
| M4     | 4.2 mm                 |
| M5     | 5.2 mm                 |
| M6     | 6.3 mm                 |
| M8     | 8.4 mm                 |

なお、[タッピングことはじめ](tapping_threads.md)で説明したとおり、
普通のタッピングの下穴径は「ねじ径 − ピッチ」になります。
つまり、一般にタップ下穴は、目標めねじ径より「ちょっと小さい」です。
（あたりまえですね。）
一方ヘリカルインサートの場合、
挿入するコイルやビットの厚みがあるため、
そのぶん太いめねじをワークにたてる必要があります。
よってそのためのタッピング下穴は、上記の表のとおり、
目標めねじ径より必ず「ちょっと大きい」のです。

これはすなわち、母材に直接切って使用していためねじがつぶれた場合、
穴位置を変えずに、
その同一箇所をヘリカルインサートで置換できる、
ということです。
たとえば、樹脂のワークにM3のめねじを切ってつかっていたとします。
そのねじがガバになってきた場合、
それを&#x2300;3.1mmのドリルでさらって、
あらたにM3インサート用タップを切り、
ヘリカルインサートを施工することができます。
穴位置は変える必要がないため、
固定相手側の追加工の手間を防ぐことができます。

### 抜去工具

挿入工具と同様、タングレスは抜去工具も専用品です。
必要なら、これも各サイズ、
挿入工具とはべつに購入する必要があります。
わたしはさすがに、今回、抜去工具は見送りました。
必要になった時点で、必要なサイズだけ購入することになると思います。
その間、しごとが止まるので、
本来であればあらかじめ揃えておきたいところなのですが……。
必要になるかわからない抜去工具まで、
各サイズ買っとくのも、ね。

### タップ穴深さ

前述のとおり、タングレスの施工における母材へのタッピングは、
径こそ違えど、作業的に普通のタッピングと差はありません。
その意味で、加工そのものの技術は本質的におなじです。
ただ、タッピング深さの決めかたが、
すこしシビアな印象をもちました。

前提として、タングレスなどのヘリカルインサートは、
止まり穴に施工することが多いと思います。
（通し穴なら、裏手に板付きナットや圧入インサートを仕込むなど、
べつの手がつかえるためです。）
その際、挿入のための下穴やタップは、
できれば必要最低限であけたいのが人情です。
よって、ただ漠然とタッピングする場合と比べると、
必要な深さまで過不足なくタップを切る技術がちょっと要ります。

仮にタップが浅過ぎたら、コイルが挿入しきれなくなるため論外です。
一方、深すぎるタップ穴を切ると、
そのぶんコイルを深く挿しすぎる可能性が生じます。
コイルの挿入深さは挿入工具で設定するとはいえ、
ボルトの抜き差しによりズレていく可能性もあります。
できれば過不足ない深さで切っておきたい。

しかしながらコイル型インサートは、これも前述のとおり、
元サイズよりもすぼまされながら挿入されます。
その際、挿入前のコイルよりも全長がすこし伸びることになるのです。
よって、挿入前の金物の長さ（+1山）ピッタリにタッピングをすると、
コイルが入りきりません。
いちおう製品規格として、挿入後のめねじ長さも提示されてはいるものの、
ぴったり過不足ないタップ穴を切ろうと思ったら、
それなりの試行錯誤が必要と思います。

まあ、そんなこと気にせず深めにタッピングしちゃうことにすれば、
特別な技術は要りませんし。
それで大きな問題も起きはしない気はしますけどね。

### コイルの耐久性

施工しためねじの耐久性については、
現時点では不明です。
どのくらいのボルト脱着で、
コイルがへたれたり抜けたりするか、まだわかりません。
以前つかっていたヘリサートも、
最終的には抜けてきたので、
ある程度それは宿命なのかなと考えています。

どちらかというと重要なのは、
コイルがへたってきた場合、
抜去と再施工がどのくらい容易・現実的か、という点。
弱ったコイルを無理やり抜くと、
母材のタップ穴側も同時に壊してしまい、
おなじ箇所におなじサイズのインサートは施工できなくなります。
タングレスは専用の抜去工具があるため、
母材を傷めずに古いコイルを抜き、
あたらしいものに替えられるんじゃないかと期待しています。

### 挿入工具の耐久性

挿入工具側の耐久性についても、
現時点ではわかりません。
いちおう公式にも、多量の施工を繰り返すと工具の爪が変形し、
コイルにきちんとかからなくなるとされています。
そのための替えの爪も販売されていますが、
これがまた1本9千円弱で、バカ高い。
挿入工具自体が1.3万なので、
「それよりは安いでしょう？」ってことでしょうが、
さすがにアコギな商売だと思います。

また、この爪がけっこう折れやすいというネット上の評判もあるのですが……。
これについてはちょっと懐疑的で、
そんなに頻繁には折れないだろうと楽観しています。
というのも、爪が折れるという件には、ちょっと思い当たるふしがあります。
タングレスの挿入って、作業している感覚としては、
ドライバで普通のねじを締めているときと近いです。
そのせいで、挿入終わりで「クッ、クッ」とトルクをかけて増し締めしたい感覚になります。
というか、わたしも実際、
なんとなくの流れで最初そうやってしまいました。

たしかに普通のねじであれば、
これによってねじの頭がワークに押しつくことで、
ねじ山に応力を発生させます。
ただタングレスの挿入の場合、やりたいことはあくまで
「定位置にコイルを置いてくる」だけです。
コイルがその場に留まるのはスプリングバックの作用であって、
ねじ山間の応力ではありません。
よって、タングレスの挿入でそのような増し締めは無意味です。
そういう余計な負荷を挿入工具にかけなければ、
爪もそう簡単に折れたりしないのではないでしょうか？

まあ、現状ただの想像なので、実際のところはわかりません。
今後、挿入工具側の耐久性で気づいたことがあれば、
追記したいと思います。
