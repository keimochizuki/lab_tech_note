# ヘリサートと、Eサートと、エンザートと

ヘリカルインサートを選定していて、すぐ忘れてしまうので、
備忘のためまとめました。

## ヘリカルインサートとは

そもそも「ヘリカルインサート」とは何か。
簡単にいえば、専用の金物を樹脂に埋め込んで、
強いめねじをつくるためのものです。
「ヘリサート」や「リコイル」という呼称のほうが、
一般的かもしれません。
ただ、特定の製品を指す商品名になっていたり、
いちばん一般的な「ヘリサート」がいまは商品名としてなくなっていたり
（ライセンス契約上の都合）、
こまごま面倒なことがあります。
なので本記事では、それらの技術一般を指す名称としては
「ヘリカルインサート」を用いることにしました。

### ヘリサート

専用タップで切っためねじにバネ状の金物をねじ込んで、
強い金属めねじをつくる方法。
ヘリカルインサートのなかでもっとも基本となるものだと思います。

ねじ込む際に無理をすると、
母材のめねじに対して1山飛びでバネが入ってしまう「ピッチ飛び」が生じます。
ピッチ飛びしたヘリサートは、もう使用できません。
また、先端の「タング」部分をつまむかたちでねじ込んだのち、
最後にこれを折り取る作業が必要です。
これによってもピッチ飛びの可能性があります。
挿入やタング抜去には、専用工具を用います。
それから、母材に切るめねじも特殊サイズであるため、
専用のタップが必要です。
総じて、施工技術的にも作業時間的にもデメリットが目立ちます。

呼称がややこしい原因でもあります。
もともとは(株)ツガミが米国企業とのライセンス契約により製造していた商品名です。
その契約が終了したため、いまはEサートという商品名となり、
製造も(株)インサートに事業譲渡されています。
また、日本スプリュー(株)は「スプリュー」、
リコイルジャパンは「リコイル」の名称で、
おなじ機構の製品を製造しています。

### タングレス

モノ自体は、ヘリサートとおなじバネ形状ながら、
タング抜去の面倒さを解消した製品です。
タングの代わりに、バネ端部の内側につくられた切り欠きをつかって、
母材に挿入します。
タングを折る作業が不要となるだけでなく、
それにともなうピッチ飛びの恐れもなくなります。
また、挿入工具の仕様上、
挿入時にピッチ飛びする可能性もほぼありません。

### イリサート

コイル式のインサートに対して、
「一体物で同様の形状をつくっちゃえば、そもそもピッチ飛びとかしないじゃん」
という方針に舵を切った製品。
内側も外側もねじが切ってある金属ブッシュを母材のめねじに挿入して、
金属めねじをつくるしくみです。
母材にめねじを切るタップが、市販タップでよいという利点があります。

一体の筒なので、外ねじに接着剤を塗って挿入できます。
（コイル型では、内ねじに侵入してしまうため接着剤がつかえない。）
というか、接着剤を併用しないとそのうち抜けてきてしまう気がするのだけど、
どうなのでしょう？

### エンザート

前述のイリサートと同様の一体物のブッシュですが、
外ねじがセルフタップのねじになっています。
よって、規定サイズで母材にあけた下穴に、
エンザートをねじ込んでいくだけで施工が完了します。
ボルト・ナットをつかって工夫すれば、
専用工具ななくても挿入できる利点もあります。
デメリットは、高い。



## で、どれがよい？

作業性重視で考えるとイリサートなのかな
（専用タップも要らず非コイル式で強度も高い）
……と思っていましたが、
執筆現在、モノタロウで取り扱い停止サイズが増えていっているのが気にかかります。
メーカ規模も他と比べると小さめなので、
もしかしてヘリカルインサート事業が縮小傾向だったりしないよな……。
いうて挿入工具などは専用なので、
揃えてからモノ自体が終売になったりすると悲しいです。

ということで、時点でタングレスかなぁというのが現在の私見。
タップを切る作業自体は、個人的に苦手意識はないので、
あとは挿入が簡単で失敗がない点が重要です。
エンザートは単価が高いことに加え、
金属（たとえばアルミ）相手でもセルフタップが充分利くのか実感がわきません。
メーカ公称では可能ということになってはいるのですけどね。
