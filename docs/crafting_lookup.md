# 実験屋の逆引き器械工作辞典

実験研究では、さまざまなレベルの器械加工が往々にして必要になります。
なんでもかんでも業者さんにお願いしていると高くつくし、
それ以上に、研究のテンポが悪くなります。
（そもそも田舎では、お金がかかるという以前に、
頼める業者さんがなかったりします。）
ちょっとしたことであれば、自分で工作できると非常に便利です。

このページでは、筆者が所属教室で担当するそんな器械工作を、
逆引きのかたちで集めてみました。
必要な機能に対して、それを実現する方法にどんなものがあるかをサッと調べる、
あるいは事前に知っておくために、活用してもらえれば嬉しいです。



## 注意事項

- すべての内容は「筆者が考える第一選択」であって、唯一解とは限りません。
- 筆者自身、記載したすべての作業に精通しているわけではありません。
- アスタリスク＊付きは、一般的にやや高難度と考えられる作業です。
- 作業は充分な手順確認ののち、安全第一で、自らの責任のもと行なってください。
- 本文書内容に起因した怪我や不利益について、筆者は一切責任を負いません。
